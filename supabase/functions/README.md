# مصادر دوال الحافة

نسخ مطابقة لما هو **منشور فعلاً** على Supabase (المشروع `wxrukupcyfypnqnotmxv`).
نُشرت كلّها هناك في ٢٠٢٦/٠٨/٢٢ مع نقل المشروع.
حُفظت هنا لأن الدوال كانت تعيش على Supabase وحدها بلا أثر في المستودع — فمراجعة
تغييرٍ فيها كانت مستحيلة، وأي تعديل يضيع تاريخه.

| الدالة | verify_jwt | التوثيق |
|---|---|---|
| `api/` | ❌ | مفتاح `cm_live_…` في ترويسة Authorization (§14) |
| `paylink-order-create/` | ❌ | لا يحتاج — الزبون على الطاولة ليس مسجَّلاً (§13) |
| `order-verify/` | ❌ | نفس السبب: يسأل PayLink بمفاتيح المطعم (§13) |
| `menu-scan/` | ✅ | جلسة تاجر + ملكية المطعم + حدّ معدّل |
| `migrate-images/` | ❌ | رمز لمرّة واحدة من `internal_secrets` — **حُذف الرمز بعد الانتهاء** |

⚠️ **النشر لا يتم من هنا تلقائياً.** تعديل الملف هنا لا يغيّر الدالة المنشورة —
انشرها عبر أدوات Supabase ثم حدّث الملف ليطابقها. الملف توثيق ومراجعة لا مصدر
نشر.

الدوال الأخرى (`founder-admin` · `moyasar-webhook` · `payments` ·
`paylink-create` · `paylink-webhook` · `notify-support` · `dynamic-task`)
ما زالت على Supabase فقط.
