كلاود منيو — دليل النشر بالسحب على Netlify
==========================================

هذا المجلد (deploy/) هو الموقع الجاهز كاملاً. لا يحتاج بناءً ولا متغيّرات بيئة.


الخطوات
-------
1) نزّل المستودع من GitHub (زر Code ← Download ZIP) وفكّ الضغط.
2) افتح https://app.netlify.com ثم موقعك ← تبويب Deploys.
3) اسحب مجلد deploy/ **كاملاً** وأفلته في منطقة السحب.
4) انتهى — الموقع يعمل فوراً بكل صفحاته.


⚠️ الخطأ الأشهر: سحب ملف index.html وحده
-----------------------------------------
اسحب **المجلد** لا ملفاته المفردة. داخل المجلد ملفان يبدآن بشرطة سفلية
لا غنى عنهما:

  _redirects  ← بدونه تعطي /login و/dashboard وروابط المطاعم /<slug>
                خطأ 404، ولن تستطيع تسجيل الدخول إطلاقاً.
  _headers    ← ترويسات الأمان (CSP) والتخزين المؤقت.

إن رأيت 404 على /login بعد النشر فالسبب دائماً أن _redirects لم يُرفع.


ما الذي يحتويه الموقع
---------------------
• صفحة المنيو العامة /<slug>: الأصناف والتصنيفات والبحث، خيارات وإضافات
  الأطباق، سلة الطلب، إرسال الطلب على واتساب، الدفع الإلكتروني (إن فعّله
  المطعم)، بطاقة الولاء، تقييم الزبون، وروابط التواصل.
• لوحة التاجر /dashboard: الأطباق، القوائم، أكواد QR، التحليلات، التقييمات،
  الولاء، المستشار الذكي، الاشتراك، الدعم الفني، والإعدادات.
• لوحة المؤسس /founder: نظرة عامة وإيرادات، المطاعم والاشتراكات، تذاكر
  الدعم، أكواد الخصم، الإعلانات، والمدونة.


الحسابات والبيانات
------------------
الموقع متصل بقاعدة Supabase نفسها — حساباتك ومطاعمك وبياناتك تعمل مباشرة
بلا أي إعداد إضافي.


المدفوعات
---------
البوابة PayLink. **لا يوجد أي مفتاح دفع داخل هذا المجلد**: المفاتيح أسرار
خادم تعيش في أسرار دوال Supabase وحدها، والمبلغ يُحسب على الخادم لا في
المتصفح. للتبديل من التجربة إلى الإنتاج غيّر PAYLINK_ENV والمفاتيح في أسرار
الدوال — بلا إعادة بناء ولا إعادة نشر.


التعديل مستقبلاً
----------------
الكود المصدري في مجلد app/. عدّل ثم نفّذ داخله:

  npm install
  npm run build

يتحدّث محتوى deploy/ تلقائياً، ثم اسحبه من جديد إلى Netlify.
