# ECC — إعداد المستودع

[ECC](https://github.com/affaan-m/ECC) طبقةُ تشغيل للوكيل: وكلاء ومهارات وأوامر
وhooks وقواعد. رُكِّب هنا **محلياً داخل `.claude/`** — الملفات ملتزَمة في git،
فتصل في كل جلسة على أي جهاز، وفي جلسات الويب والحاويات البعيدة أيضاً حيث لا
تُحمَّل الإضافات.

## ما رُكِّب — وأين

| الموضع | العدد | ما فيه |
|---|---:|---|
| `.claude/agents/` | ٦٧ | تخطيط · مراجعة · إصلاح بناء · أمن · معمار |
| `.claude/skills/` | ٢٨٤ | TDD · بحث · أمن · توثيق · واجهات · بيانات · تشغيل |
| `.claude/commands/` | ٩٤ | مداخل سريعة (طبقة توافق، وECC يتحوّل إلى المهارات) |
| `.claude/hooks/` + `.claude/scripts/` | — | زمن التشغيل: إنفاذ، ملخّصات جلسة، تعلّم مستمرّ |
| `.claude/rules/ecc/` | ٤ حزم | `common` · `typescript` · `react` · `web` |
| `.claude/ecc/setup.json` | — | بروفايل الـhooks (`standard`) ومفتاح الإطفاء |

**مهاراتك الثماني سليمة.** `graphify` و`design` و`brand` و`slides` وأخواتها لم
تُمسّ. وعند تعارض الاسم الوحيد — `design-system` — **أبقى المُركِّب نسختك**
وتخطّى نسخة ECC، وهذا سلوكه المقصود لا مصادفة.

**القواعد أربع حزم لا ٢٣.** التركيب الكامل يجلب كل اللغات؛ حُذفت التسع عشرة
التي لا تخصّ المشروع (Cisco، HarmonyOS، Perl، Swift…). المتبقّي يطابق المكدّس.

## الـhooks — كيف تعمل هنا، ولماذا لزمها تعديل

hooks ECC مكتوبة لتركيب في `~/.claude` أو لإضافة، فمُحلّل جذرها يبحث في
**مجلّد المنزل**. في تركيب داخل المشروع كان يعود بـ`/root/.claude` — لا ECC
هناك — فتفشل كل نداءات Bash وWrite وEdit.

الحلّ: كل أمر hook في `settings.json` مسبوق بـ

```
CLAUDE_PLUGIN_ROOT="$CLAUDE_PROJECT_DIR/.claude"
```

`$CLAUDE_PROJECT_DIR` يملؤه Claude Code وقت التشغيل، فالمسار **نسبيّ لا مطلق**
ويعمل على أي جهاز وأي نسخة من المستودع. **لا تستبدله بمسار مكتوب بيد** — يعمل
عندك ويكسر عند غيرك.

hooks الـgraphify القائمة بقيت أولاً في `PreToolUse`، وhooks ECC أُلحقت بعدها.

### GateGuard — أول ما ستلاحظه

بروفايل `standard` يفعّل **بوّابة تحقّق** تحجب أوّل أمر Bash في الجلسة (وإنشاء
الملفات) حتى تُذكَر الحقائق: ما الطلب · ما الذي يتحقّق منه الأمر · هل يوجد ملف
يؤدي الغرض. هذا سلوك مقصود من ECC لا عطل. لإطفائه:

```bash
ECC_GATEGUARD=off                      # للجلسة
```

أو أضِف `pre:bash:gateguard-fact-force` و`pre:edit-write:gateguard-fact-force`
إلى `disabled` في `.claude/ecc/setup.json`. ولتخفيف الـhooks كلها:
`"profile": "minimal"`. وللإطفاء الكامل: `"enabled": false`.

## الأسبقية — `CLAUDE.md` يفوز

قواعد ECC **عامّة**، وقواعد هذا المستودع **مخصوصة ولها تاريخ أعطال**. عند أي
تعارض: `CLAUDE.md` و`docs/` هما المرجع.

تعارضان قائمان اليوم، لا تتبع فيهما ECC:

1. **رسائل الـcommit**: `rules/ecc/common/git-workflow.md` يفرض `feat:`/`fix:`
   بالإنجليزية. تاريخ هذا المستودع **جملٌ عربية وصفية** — أبقِه عربياً.
2. **بوّابة ما قبل الدفع**: §6 في `CLAUDE.md`
   (`typecheck` ← `npm test` ← `npm run build`)، لا سلّم ECC العام.

وثوابت `CLAUDE.md` السبعة (قيم الطوابع · لا `select=*` · الأعمدة المحسوبة ·
القوائم البيضاء · تكافؤ `_shared` · باقة `standard` · قفل النشر) **لا يمسّها
شيء من ECC**.

## التحديث

التركيب المحلّي **لا يتحدّث تلقائياً** — هذا ثمن ضمانه في كل جلسة. للتحديث:

```bash
git clone https://github.com/affaan-m/ECC.git /tmp/ecc
bash /tmp/ecc/install.sh --target claude-project --profile full
```

ثم أعِد الخطوتين اللتين لا يعرفهما المُركِّب: احذف حزم القواعد الزائدة (أبقِ
`common` `typescript` `react` `web`)، وتأكّد أن أوامر hooks في `settings.json`
ما زالت مسبوقة بـ`CLAUDE_PLUGIN_ROOT`. والمُركِّب يتخطّى `design-system`
تلقائياً فنسختك محفوظة.

`.claude/ecc/install-state.json` **مُستثنى من git** — يحمل مسارات مطلقة خاصة
بالجهاز.

## تنبيه — لا تُكدِّس طرق التركيب

ECC يحذّر من تركيبه مرتين في نفس الـharness: تتكرّر المهارات والـhooks
والإعدادات. هذا المستودع على **المسار المحلّي**، ولذلك **أُزيل
`enabledPlugins`** من `settings.json`. أُبقي `extraKnownMarketplaces` وحده —
لا يفعّل شيئاً، لكنه يجعل العودة إلى مسار الإضافة أمراً واحداً إن أردتَها
يوماً. فلا تشغّل `/plugin install ecc@ecc` ما دامت الملفات هنا.
